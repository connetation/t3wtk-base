Extension point rendered by Layouts/ContentElements/Default.html inside the frame div's tag. Packages layered above conn_base may override this partial (via a higher partialRootPaths index) to emit extra HTML attributes for the frame div — and register the assets they need via f:asset.css/f:asset.script. conn_base itself adds nothing. Output must be empty or valid attribute syntax, e.g.: data-foo="bar"
