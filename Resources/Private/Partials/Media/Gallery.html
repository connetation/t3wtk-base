The editor's "Columns" select (imagecols) defines the SLOT WIDTH, independent of how many images the element has: - Above/below the text: every image spans 1/cols of the content width (row-cols-{cols}); with position "center" incomplete rows are centered at every breakpoint (justify-content, _gallery.scss). - Beside / in text: cols defines the split between media area and text — cols=2 → image area 50% / text 50%, cols=3 → 1/3 vs 2/3, … (width calc(100%/cols) in _gallery.scss); images inside the area stack full width (row-cols-1); the text wraps around it when a wrapping position is selected (fsc float CSS).
